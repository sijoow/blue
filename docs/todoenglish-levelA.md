# 토도영어 레벨 A 관찰 기록

2026-11-06 사용자 폰(갤럭시 SM-S947N)의 토도영어를 adb 로 직접 해 보며 기록했다. 프로필은 **이하온**이고, 관찰하면서 Day 1·2 를 끝까지, Day 3 은 영상과 그림책까지 진행했다(하온이는 Day 3 남은 놀이부터).
캡처 217장은 `refs/todoenglish/`(깃 제외 — `/refs/`)에 있다. 파일 이름 앞 번호가 본 순서다.
소리는 들을 수 없어서 대사·발음은 빠져 있다.
**따라 만드는 것** = 하루 구성, 놀이 방식, 판 수, 정답·오답 흐름, 보상 흐름. **그림·캐릭터·소리·문구는 가져오지 않는다**(우리 그림은 블루이, 목소리는 수아·클로이).

## 1. 큰 구조

### 첫 화면 (`001-home`, `135-home2`)
- 위: ← · 토도잉글리시 간판 · 별 수 · 언어(ENG)
- 가운데: **Daily Course**(큰 카드, "Level A ▸ DAY 2") · **Free Choice**(미니게임) · **Videos**(라이브러리) · **Books**(라이브러리)
- 오른쪽: Today's Mission · Glossary(새) · AI Speaking Lab · 왼쪽: Weekly Magazine
- 하루를 끝내면 Daily Course 카드의 그림과 날짜가 다음 날로 바뀐다(Day 3 카드엔 a·b·c 쓰기 그림).

### 레벨 판 (`065-dayend-b`, `193-day2-end`)
- 「LEVEL A」 판 = **4줄 × (Day 5개 + Quiz)** = 24칸. 1줄 = Day 1~5 + Quiz, 2줄 = Day 7~11 + Quiz …(Quiz 가 6·12·18·24일째 자리).
- 끝낸 날에는 캐릭터 스티커가 붙고, 지금 날은 「Today」. 앞날은 잠김(흐림).
- 하루를 마치면 이 판이 뜨고, 별이 그날 칸 쪽으로 날아가 붙는다. 그다음 첫 화면.
- **하루 제한 없음** — 하루를 끝내자마자 다음 날을 바로 할 수 있었다.

### 하루 화면 (`002-daily`, `136-day2`, `195-day3`)
- 위: 레벨·날 간판(「A LEVEL DAY 2」) · REVIEW 단추 · 별 수 · 오른쪽에 Mission·Glossary 단추.
- 왼쪽 큰 칸: **Today's Video**(제목·길이). 오른쪽: 놀이 아이콘(3~5개)과 **말풍선 칸**(글자·인사말). 아래: **그림책** 또는 말풍선.
- 순서: **영상을 먼저 봐야** 나머지가 열린다(안내 캐릭터가 "먼저 영상을 보자!", 손가락이 영상을 가리킴). 그다음은 **순서 자유**. 1일째만 그림책이 놀이 3개 뒤에 열렸고, 3일째 그림책은 영상 뒤 바로 열렸다.
- 끝낸 칸은 보라색으로 덮이고 노란 ✓. 다시 누르지 않는다.
- 칸마다 끝나면 **「Great!」 별 1개** → ✓ 단추 → 하루 화면. 하루를 다 끝내면 별 5개가 더 붙는다.

- 같은 놀이가 여러 날 되풀이된다(Literacy Matching·Find The Pair 는 Day 2·3 둘 다).

## 2. 놀이(레벨 A에서 해 본 것)

공통: 위 가운데 **점 = 판 수**(지금 판은 노란 점, 끝낸 판은 파란 점), 왼쪽 위 ← 나가기. 처음 하는 놀이는 「How to Play」 짧은 시범(손가락)이 먼저 나온다. 끝은 늘 「Great!」 별.
레벨 A 의 판은 **A·B·C·D 네 글자**를 돈다. 판이 늘수록 **1~2판은 글자 두 개씩, 마지막 판은 넷을 모아** 복습하는 흐름이 많다.

| 놀이 | 하는 일 | 판 | 정답·오답 |
|---|---|---|---|
| **Jewel Miner**(보석 캐기, `007`~`018`) | 동굴 벽 팻말의 목표 글자 보석을 모두 톡. 다른 글자·같은 글자 다른 글꼴이 섞임 | 4판(A→B→C→D), 판마다 3개 | 맞으면 보석이 수레로, 틀린 보석은 흔들림. 다 모으면 수레가 다음 벽으로 |
| **Missing Letter**(빈칸 알, `020`~`028`) | 알 넷에 A B C ? 처럼 빈칸 — 아래 보기 셋 중 맞는 글자를 끌어 넣기. 보기에 아직 안 배운 E F G 도 | 3판 | 틀리면 제자리로 돌아감, 맞으면 알이 깨져 새가 나옴 |
| **Paint the Word**(그림 말하기, `030`~`052`) | 밑그림을 보고 마이크에 단어를 말하면 붓이 색칠하고 단어 글자가 나옴 | 4판(apple·bear·cat·dog) | 채점 없음, 소리가 안 들리면 몇 번 뒤 넘어감 |
| **Break n Build**(펭귄 다리, `151`~`158`) | 다리의 빈칸에 얼음 글자를 끌어 넣어 A B C D 순서 맞추기. 다 맞으면 펭귄이 다리를 건너 물고기를 먹음 | 3판(빈칸 2 → 2 → 4) | 틀린 칸엔 안 들어감 |
| **Literacy Matching**(짝 카드, `159`~`163`) | 같은 그림 카드끼리 끌어 겹치기(apple·bear·cat·dog) | 3판(2쌍 → 2쌍 → 4쌍) | — |
| **Find The Pair**(그루터기, `164`~`171`) | 그루터기 위 글자와 같은 글자 카드를 골라 옆 빈칸에 끌기(글꼴이 다른 같은 글자) | 4판(A→B→C→D), 보기 2장 | 틀리면 제자리로 |
| **Pet Dictation**(여우 받아쓰기, `172`~`184`) | 단어(apple)를 들려주고 마이크에 말하면 여우가 칠판에 받아 적음 | 4판(apple·bear·cat·dog) | 못 알아들으면 3번 뒤 넘어감. 끝에 말한 단어 4개를 모아 보여 줌 |
| **Alphabet Puzzle**(나무 판, `084`~`089`) | A~Z 나무 판의 빈 자리에 오른쪽 글자 조각 끌어 넣기 | 3판(A·B → C·D → A~D 넷) | 맞는 자리에만 들어감 |
| **Letter Writing**(모래 쓰기, `110`·`198`~`204`) | 모래 위 글자의 획을 화살표·점선 따라 손가락으로 긋기. 획을 다 쓰면 그 글자 단어 카드(Apple) | 4판(A → a → …) | 획 길을 벗어나면 안 칠해짐 |
| Picture Puzzle(`092`) | 사과 그림자에 조각 2개를 끌어 맞추기 | 4판 | (완성 못 봄) |
| Coloring Monster(`098`) | 괴물 색칠 | — | (짧게만 봄) |
| Flash Card(`107`) | 단어 그림 카드 넘기며 듣기 | — | (짧게만 봄) |
| Letter Tracing Card(`119`) | 카드 세 장(a·t·p)의 글자를 점선 따라 긋기 | 2판 | (짧게만 봄) |
| Finger Trace(`129`) | 직선 긋기 연습(화살표 → 끝까지) | 3판 | (짧게만 봄) |

### Free Choice(`068`~`073`, `082`, `100`, `124`, `131`)
- 놀이 50개 가까이. 위 줄에 영역(전체·알파벳·파닉스·듣기·어휘·쓰기·말하기·책). 놀이마다 **열리는 레벨**이 정해져 있다(잠긴 놀이엔 「Level D」 같은 자물쇠).
- 레벨 A 에서 열린 것: Jewel Miner · Missing Letter · Paint the Word · Alphabet Puzzle · Picture Puzzle · Find The Pair · Flash Card · Letter Writing · Letter Tracing Card · Literacy Matching · Coloring Monster · Pet Dictation · Finger Trace · Break n Build.
- 놀이를 누르면 시작 창(설명 한 줄 · Play count · **단계 1~8**). 한 판을 끝내면 다음 단계가 골라져 있다.

### 영상·그림책
- 영상은 데일리 코스 칸 안에서 재생(위 제목, 오른쪽 위 소리 조절), 끝나면 「Great!」.
- **그림책은 그날 글자의 단어로 만든 짧은 반복 이야기**다. 「Apples」(Day 3): Apple. → Apple for Bear. → Happy Bear. → Dog → Cat → "No apple!"(반전). 배운 단어는 빨간 글씨. 표지에 제목·글·그림 작가, 오른쪽 위 읽어 주기 단추, 양옆 화살표로 넘김, 아래 쪽 번호(1/9).
- Day 1 그림책 「Hello, Baby!」는 인사 표현(Hi, Mom! …) 7쪽.

## 3. 우리 앱(영어교실)과 비교

| | 토도영어 레벨 A | 영어교실 지금(11-05) |
|---|---|---|
| 한 단위 | 5일 + Quiz(유닛) | 미션 13개(★4·★★4·★★★4·도장) |
| 하루 | 영상 1 + 놀이 3~5 + 말풍선 0~3 + 그림책 0~1 = 5~9칸 | 오늘의 길 10칸 |
| 하루 순서 | 영상 먼저, 나머지 자유 | 칸 차례대로 |
| 새 글자 | 유닛 첫날부터 A~D 넷을 같이(판마다 한 글자씩 돈다) | 하루에 하나씩 |
| 판 | 놀이마다 3~4판, A·B·C·D 를 돌고 마지막 판은 모아서 | 놀이마다 1~4판 |
| 보상 | 칸마다 별 1 + 하루 끝 별 5, 레벨 판 스티커 | 칸마다 스티커 1 + 미션 끝 3 + 도장 5 |
| 하루 제한 | 없음 | 처음엔 꺼짐 |
| 말하기 | 그림 색칠·여우 받아쓰기(못 알아들어도 넘어감) | 따라 말하기(녹음 → 다시 듣기) |
| 쓰기 | 획 화살표 따라 긋기 → 단어 카드 | 칸 덮기 따라 쓰기 |

반영 후보는 사용자와 정한다(이 문서는 관찰만).
