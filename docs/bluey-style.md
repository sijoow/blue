# 블루이 그림체 — 생성 프롬프트 기준 (2026-10-28)

영어교실 그림(안내 친구·단어 그림·아이콘·놀이터 장면·바탕)을 힉스필드에서 만들 때 쓰는 기준이에요. 근거는 사용자가 넣어 준 `refs/` 세 장을 확대해 본 것이에요(지어내지 않는다). 프롬프트 문구는 `scripts/image-style.mts`에 있어요.

## 1. 레퍼런스

| 원본 | 내용 | 생성용 사본(`node scripts/refs-clean.mts`) |
|---|---|---|
| `refs/12.png` (340×600) | 한국어 위키 화면 캡처 — 블루이 가족 포스터(아빠·엄마·블루이·빙고), 위에 BLUEY 로고·롤링스톤 배너 | `refs/gen/family.png` — 포스터 속 가족과 마을 배경만 |

| `refs/567.jpg` (695×512) | 블루이·빙고·아빠 밴딧·엄마 칠리 등 22명 + 이름표 | `refs/gen/bluey.png` · `bingo.png` · `bandit.png` · `chilli.png` — 이름표 위까지만 한 명씩 |

생성기는 레퍼런스의 글자를 베낀다(숫자놀이 때 겪음) — 그래서 이름표·로고는 잘라 냈다. 여러 캐릭터가 함께 있는 레퍼런스는 결과에도 다른 캐릭터가 섞이니, 한 캐릭터만 그릴 때는 "Only Bluey. No other characters anywhere."를 꼭 넣는다.

## 2. 관찰한 그림체

- **평면 2D 애니메이션** — 매끈한 단색 면, 아주 옅은 그림자 한 단계. 질감·광택·3D 없음.
- **테두리** — 검은 선이 아니라 몸 색보다 조금 진한 같은 계열 색의 얇은 선(파란 몸은 진한 파랑, 주황 몸은 진한 주황).
- **얼굴** — 큰 하얀 타원 눈 + 검은 동그란 눈동자(작은 하얀 반짝임), 눈 위 진한 색 눈썹 무늬, 짧은 주둥이 끝 검은 코, 단순한 입.
- **몸** — 둥근 네모꼴 몸통, 짧은 팔다리, 뾰족한 큰 귀, 꼬리. 사람 손가락 대신 단순한 앞발.
- **색** — 하늘색·남색(블루 힐러), 주황·크림(레드 힐러), 밝고 따뜻한 낮 햇빛. 파스텔보다 조금 더 맑은 색.
- **배경(포스터)** — 호주 브리즈번 집 마당: 기둥 위 퀸즐랜더 집, 야자수·열대 나무, 꽃, 연두 잔디, 맑은 하늘. 단순한 모양으로.

## 3. 캐릭터 (이름은 refs 이름표 그대로, 한국어 표기는 사용자 확인 전 — 화면에는 아직 이름을 쓰지 않는다)

**주인공 = 블루이 가족 넷**(2026-10-28 사용자: 가족 포스터를 보여 주며 "애들이 주인공이야") — 한글나라의 페파 가족처럼. 안내·소개는 블루이.

## 4. 그림 종류별 요령

- **단어 그림 52장**(`word:<id>`): 물건·동물 **하나만**, 캐릭터 없이, 투명 바탕. 동물(dog·cat·duck…)도 블루이 그림체의 동물 — 단, dog 는 블루이·빙고가 아닌 다른 강아지("not Bluey, not a heeler").
- **안내 친구 3장**(`guide` · `guide:cheer` · `guide:wow`): 블루이 혼자, 전신, 투명 바탕.
- **아이콘**(메뉴·놀이·UI·스티커): 투명 바탕, 단순하게. 메뉴 아이콘만 블루이·빙고가 그 놀이를 하는 모습.
- **놀이터 장면 6장**(4:3) · **바탕 5장**(16:9): 마당 배경, 바탕은 가운데를 비워 카드가 올라갈 자리.
- 공통: 글자·로고·워터마크 없음(알파벳을 그림에 넣지 않는다 — 생성기가 글자를 틀리게 그린다. 글자는 앱이 프리텐다드로 쓴다).

## 5. 확인 순서 (숫자놀이와 같게)

시험 3장(안내 친구·apple·dog) → 어두운 바탕 모음 한 장으로 확인 → 본 생성 → 내려받기 → `npm run image:install -- drafts/<날짜>` → `npm run image:upload` → 사용자에게 "힉스필드에서 지워도 돼요".
