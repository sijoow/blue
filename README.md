# 하온이의 영어교실

4살 아이를 위한 집에서 쓰는 영어 놀이 앱. 형제 앱 「하온이의 한글나라」(`Desktop/todo`)·「하온이의 숫자놀이」(`Desktop/nmber`)와 같은 화면 틀·목소리·로그인을 쓰고(숫자놀이를 복사해 시작, 2026-10-27), **로그인 계정과 아이 정보·설정은 한글나라에서 받아온다**(같은 MongoDB, 한글나라 DB 는 읽기만).
과정은 토도영어 데일리 코스의 레벨·유닛 순서를 따른다 — 지금은 레벨 A(A~P)·B(Q~Z + 복습) 8장 × 6일 = 48일. 사용자 범위는 4~6세 = 레벨 A~E(알파벳 → 파닉스 → CVC)라 C~E 를 이어서 넣는다. 그림은 블루이(집에서만 쓰는 앱, `refs/`).

## 실행

```bash
npm install
npm run dev          # http://localhost:6500 (6400 은 예산 대시보드가 쓴다)
npm test             # 과정표·판 만들기·진도·스케줄·한글나라 값·로그인 검사
npm run voice:lines  # 들려줄 말 목록 → scripts/voice-lines.json (한국어 안내·단어 뜻 / 영어 글자 이름·단어)
npm run voice:reuse  # 한글나라·숫자놀이에 이미 구운 같은 말 빌려 오기 (크레딧 안 씀)
npm run voice:make -- --voice sua          # 한국어 남은 말 견적만 (--yes 를 붙이면 굽는다) — 영어 줄은 빼고 굽는다
npm run image:list && npm run image:prompts # 그림 목록·프롬프트 → scripts/image-prompts.json (레퍼런스는 node scripts/refs-clean.mts → refs/gen/)
npm run image:install -- drafts/<날짜>     # 힉스필드 결과(results.json) 내려받기 → public/img WebP + image-manifest(?v=내용 해시)
npm run image:upload                      # public/img → 회사 Cafe24 /app/img/lsh/eng/
```

`.env.example` 을 `.env.local` 로 복사해 채운다 — 값은 숫자놀이와 같고 `MONGO_DB=haonenglish` · `CAFE24_UPLOAD_DIR=/app/img/lsh/eng/` 만 다르다.
Vercel 환경변수: `MONGODB_URI` · `MONGO_DB` · `HANGUL_DB` · `ACCOUNTS` · `AUTH_SECRET` · `CAFE24_PUBLIC_BASE_URL` · `CAFE24_UPLOAD_DIR` (그림 주소는 빌드 때 정해지니 값을 넣고 다시 배포).

## 과정 — 토도영어 레벨 A·B (`src/curriculum/course.ts`)

장 하나 = 업체 유닛 하나, 6일 = 5일 놀이 + 6일째 **도장 퀴즈**(업체 유닛 테스트 자리 — 단어 미리 보기 → 10문항, 앞 장 글자 2문항). 80% 이상이면 도장, 결과는 업체 트로피처럼 동(80 미만)·은(80 이상)·금(100), 장마다 가장 좋은 결과가 남는다. 못 받으면 업체처럼 **6일 추가 학습**(그 장 1~5일 다시 → 퀴즈 한 번 더) → 그래도 못 받으면 다음 장. 새 글자는 하루에 하나.
**하루 = 노래 → 그림책 → 활동**(업체 하루: 영상 → 책 → 액티비티, 2026-10-28 사용자: 토도 구성 따라가기). 노래는 이미 구운 글자·단어 소리를 이어 부르는 챈트("A, A, apple"), 그림책은 표지(가족) → 단어 쪽 → The End.
지난 날은 첫 화면 레벨판(◀ ▶ 로 장 넘기기)에서 점을 눌러 언제든 다시 한다(`/play?review=c1d3` — 진도 그대로, 지난 퀴즈면 메달만).

| 장 | 유닛 | 글자 | 하루하루 |
|---|---|---|---|
| 1~4 | A1~A4 | ABCD · EFGH · IJKL · MNOP | 1~4일 새 글자 하나씩 만나기 · 5일 모아서 복습(+앞 장까지 '다음 글자') · 6일 도장 퀴즈 |
| 5 | B1 | QRST | 위와 같음 |
| 6~7 | B2·B3 | UVW · XYZ | 1~3일 새 글자 · 4·5일 복습 · 6일 도장 퀴즈 |
| 8 | B4 | 복습 | A~I · J~R · S~Z · 헷갈리는 글자(b d p q, m n u w) · 전체 · 도장 퀴즈(26자) |

글자마다 대표 단어 둘(`src/curriculum/alphabet.ts`, X 는 끝 글자 box·fox).

## 놀이 12가지 (`src/components/play/activities`)

노래(챈트) · 그림책 · 따라 말하기(듣고 녹음 → 내 목소리 → 다시 듣기, 녹음은 남기지 않음, 업체도 AI 채점은 C부터) · 도장 퀴즈 · 알파벳 만나기(대문자·소문자 누르기 → 단어 둘) · 글자 찾기(듣고 고르기) · 짝꿍 찾기(대문자를 소문자 위로 **끌어 놓기**) · 빈칸 글자(단어 그림 + `_pple` 빈칸에 **끌어 놓기**) · 그림 고르기(단어 듣고) · 글자 방울(대·소문자 섞인 방울 중 그 글자 모두 터뜨리기) · 다음 글자(A B C ?) · 따라 쓰기(대·소문자, TraceBoard).
보기를 누르면 이름(영어)을 먼저 읽고 딩동댕/땡, 정답은 칭찬을 끝까지 듣고 넘어간다(`lib/answer`). 판은 시작할 때 섞는다(`lib/rounds.ts`, 순수 함수 + 테스트). 힌트(다음에 누를 것·정답 자리)는 `.hint` 노란 외곽선 — `.squish` 그림자가 Tailwind ring 을 덮어서 outline 으로.

## 메뉴

업체 메뉴 구성을 따른다 — 오늘의 영어(데일리 코스, 첫 화면 레벨판 카드) · 놀이터(프리초이스 — 놀이 7가지, 처음 나온 날부터, 아는 글자로) · 노래(비디오 도서관) · 그림책(그림책 도서관) · 단어장(만난 글자와 단어) · 글자 쓰기(대문자 → 소문자) · 부모·관리자 페이지(첫 화면 톱니 1.5초 꾹). 노래·그림책은 장마다 하나 + A~Z, 그 장 글자를 다 만나면 열린다. 레벨 테스트는 C~E 레벨이 생긴 뒤에.
보상 = 스티커(놀이 1 + 하루 끝 3 + 도장 5, 놀이터는 놀이마다 하루 첫 판 1).
화면 보기(세로·가로) = 부모 페이지 「프로그램 관리」에서 영어교실만 따로 고른다(Settings.orientation, 영어교실 DB) — 안 고르면 한글나라 설정. 세로 화면 머리줄은 폰 카메라 자리만큼 내린다(`globals.css` `pt-safe`, 전체 화면 앱이라).

**영어 놀이**(`/games`, 우리가 같이 만든 오리지널 — 2026-10-28 사용자 "너가 생각한거 다 넣어보자", 업체 메뉴에 없는 우리 것) — 늘 열림, 아는 글자로(모자라면 알파벳 차례로 채움), 스티커는 놀이마다 하루 첫 판 1. 목록 `curriculum/originals.ts` · 판 만들기 `lib/originals.ts`(+테스트) · 화면 `components/games/`:
빙고랑 빙고!(3×3 그림판, 부르는 단어에 칩 → 한 줄이면 "Bingo!") · 우편 배달(편지 대문자·소포 그림을 소문자 우편함에 끌어 넣기, 깃발이 올라감) · 내 이름 HAON(글자를 끌어 HAON → 가족 이름 둘, 다 맞추면 한 글자씩 짚어 읽기) · 숨바꼭질(덤불을 톡 — 맞으면 그림이 튀어나옴, 아니면 잠깐 고개만) · 글자 낚시(낚싯바늘을 끌어 물고기에) · 주사위 말판(블루이랑 번갈아, 하늘에서 떨어지는 주사위, 칸을 눌러 "one, two…", 멈춘 칸 단어). 우편함·덤불·물고기·주사위는 SVG(`components/games/props.tsx`, "prop:<이름>" 그림이 생기면 그 그림).

## 목소리 (`lib/voice.ts`)

말마다 언어를 가른다 — 한글이 있으면 한국어(한글나라 설정 성우, 수아), 아니면 영어(원어민 묶음 `en`, 미국식). 한국어 안내 문장 안에 글자 이름을 넣지 않는다(한국어 목소리가 Z 를 "제트"로 읽는다) — 글자·단어는 늘 영어로 따로 한 줄.
영어도 수아(2026-10-28 사용자: "성우 그대로 수아로") — `npm run voice:make -- --voice en` 이 영어 모드(language eng, 빠르기 0.9)로 굽고, 글자 이름은 "ay·bee·see" 철자로 보낸다(관사 "어"로 읽히지 않게). 파일이 없으면 기기 음성(ko-KR / en-US).
수아 한국어 97줄(53줄은 형제 앱에서 빌려 옴) + 영어 78줄, 10-28 구움(794자, 이번 달 194,559/200,000). 굽기는 `TYPECAST_SAFE_LIMIT=198000` 을 붙여서.
